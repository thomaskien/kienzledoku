Vom Patientengespräch zur geprüften Dokumentation

KienzleDoku ist Open Source und kostenlos. Die Software erstellt aus dem Arzt-Patienten-Gespräch einen strukturierten Dokumentationsentwurf für T2med. Die KI arbeitet auf Ihrem eigenen Rechner oder einem eigenen Server in der Praxis.

Sie prüfen und bearbeiten den Entwurf, bevor Sie ihn in die Patientenakte übernehmen. Client und KI-Server lassen sich gemeinsam oder auf getrennten Rechnern einrichten.

macOS einrichten

Installieren Sie zuerst CPython 3.12 und ziehen Sie KienzleDoku.app aus dem DMG nach Programme. Für einen eigenen KI-Server öffnen Sie zusätzlich Commander installieren.app auf einem Mac mit Apple Silicon, macOS 14 oder neuer und mindestens 16 GB gemeinsamem Arbeitsspeicher.

Die Mac-Anleitung erklärt die Python-Installation, den ersten Start, die macOS-Freigabe und die Deinstallation.

Linux: Server und Client installieren

Server installieren

Für den KI-Rechner: installiert die KI-Dienste auf diesem Rechner.

wget -O install_linux.sh \
  https://kienzledoku.de/install_linux.sh && \
bash install_linux.sh --components server

In einer Root-Shell ausschließlich diesen Serveraufruf verwenden.

Client installieren

Für den Arbeitsplatz mit Mikrofon und Verbindung zum vorhandenen KI-Server.

wget -O install_linux.sh \
  https://kienzledoku.de/install_linux.sh && \
bash install_linux.sh --components client

Als angemeldeter Desktop-Benutzer ausführen, nicht als root.

Der Starter lädt die freigegebene Linux-Ausgabe, prüft die SHA-256-Prüfsumme und startet den Installer. Bis ein passendes Paket veröffentlicht ist, beendet er sich mit einem Hinweis ohne Installation.

So entsteht der Entwurf

Aus dem Gespräch wird zunächst Text. Optional werden die Sprecher zugeordnet; anschließend erstellt das Sprachmodell den Dokumentationsentwurf.

Der Commander steuert die KI-Dienste und die Modellwechsel. Connect vermittelt die T2med-Anbindung. Sie prüfen den Entwurf und geben die Übernahme in die Patientenakte selbst frei.

„Parallel geladen“ bedeutet, dass Modelle gleichzeitig im Speicher bleiben. Die Verarbeitungsschritte folgen weiterhin aufeinander.

Gute Aufnahme, verlässlicherer Text

Pegel einstellen

Bitte die Stilleschwelle so einstellen, dass auch leise Sprache erkannt wird. Eine zu empfindliche Einstellung kann Halluzinationen bei der Texterkennung begünstigen – also Text, der gar nicht gesprochen wurde.

Die Schwelle sollte über den Hintergrundgeräuschen und unter leiser Sprache liegen. −60 dBFS ist empfindlicher als −40 dBFS. „Sprache erkennen (VAD)“ hilft zusätzlich, Geräusche von Sprache zu unterscheiden. Die Stilleschwelle wirkt auch ohne VAD.

Der Balken zeigt das ungefilterte Eingangssignal. Die Einstellungen werden für diesen Client gespeichert.

Entwicklungs- und Integrationsstand, kein zertifiziertes Medizinprodukt. Den Dokumentationsentwurf vor der Übernahme vollständig ärztlich prüfen.
